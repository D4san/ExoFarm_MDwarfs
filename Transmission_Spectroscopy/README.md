# Transmission Spectroscopy

## Scientific Role

This module translates the chemically self-consistent atmospheres produced in `Photochemical_Modeling/` into observable transmission spectra and retrieval experiments. It represents the observational stage of the ExoFarm pipeline, where the question shifts from atmospheric chemistry to detectability.

The current implementation focuses on TRAPPIST-1e-like configurations and combines:

- **POSEIDON** for forward transmission-spectrum synthesis and retrieval
- **PandExo** for synthetic JWST observational noise modelling

## Current Scientific Status

The present TRAPPIST-1e spectroscopy and retrieval products derive from VULCAN
profiles that stopped at the configured maximum step count before reaching
VULCAN's global steady-state criterion (`end_case = 3`). The upstream
photochemical report identifies the remaining non-convergence as trace-species
dominated, so these spectra and retrievals are part of the active analysis, not
automatically blocked products. Interpretations must nevertheless state that
the TRAPPIST-1e chemistry is accepted with a partial-convergence caveat.

## Scientific Inputs

- pressure-temperature profiles exported from the photochemical stage
- species abundance profiles consistent with the VULCAN solutions
- stellar and planetary parameters for TRAPPIST-1e
- observing configurations for JWST NIRSpec Prism and MIRI LRS

## Scientific Outputs

- forward transmission spectra for selected atmospheric scenarios
- synthetic JWST-like datasets in POSEIDON-compatible `.dat` format
- retrieval outputs, posterior summaries, and corner plots
- diagnostic notebooks linking the true forward model to the inferred atmospheric solution

## Directory Structure

### `profiles/`
Pressure-temperature and composition profiles formatted for the spectroscopy stage. These files are the hand-off products between the chemistry and spectroscopy modules.

### `vulcan_outputs/`
Retired legacy location for raw `.vul` hand-off copies. The duplicate files
were deleted after review on 2026-06-15. Canonical `.vul` products live only in
`Photochemical_Modeling/Results/Outputs/`; new exports do not copy raw `.vul`
files unless `--copy-vulcan-dir` is passed explicitly.

### `scripts/`
Utility scripts for moving VULCAN products into spectroscopy-ready profile files.

### `notebooks/`
Exploratory and production workflows for:

- forward-spectrum generation with POSEIDON
- synthetic-observation generation with PandExo
- retrieval setup and execution
- post-processing of retrieval products

The presentation-oriented entry point is
`notebooks/ExoFarm_Transmission_Spectra.ipynb`, which compares A0-A3,
plots the forward spectra and A0-relative differences, and finishes by
generating the paired NIRSpec Prism + MIRI LRS synthetic observations.

### `notebooks/POSEIDON_output/`
Persistent products generated by POSEIDON, including synthetic data, retrieval products, and derived figures.

The current read-only inventory of scripts, plots, retrieval products, and
legacy/ambiguous outputs is documented in
[`../docs/transmission_spectroscopy_inventory_2026-06-16.md`](../docs/transmission_spectroscopy_inventory_2026-06-16.md).

### `final_products/`
Curated presentation layer for the small set of spectroscopy figures currently
used in the narrative: four-scenario synthetic spectra, noise/retrieved-spectra
figures, and the A0-vs-A3 posterior separation matrix. See
[`final_products/README.md`](final_products/README.md).

## Recommended Workflow

1. Export the current VULCAN outputs into `profiles/`.
2. Use the POSEIDON workflow to compute forward spectra for TRAPPIST-1e A0-A3.
3. Generate paired JWST-like datasets for 5, 10, 20, and 100 observations with NIRSpec Prism and MIRI LRS.
4. Run the retrieval scripts for the scenario, transit count, and instrument mode of interest.
5. Compare retrieved spectra and posteriors against the forward model.

## Observation and Retrieval Campaigns

### Synthetic observation campaign

The current synthetic-observation grid is defined for the TRAPPIST-1e
photochemical scenarios A0-A3 using the updated ExoFarm flux matrix:

| Dimension | Values |
| :--- | :--- |
| Scenarios | A0, A1, A2, A3 |
| Instruments | JWST NIRSpec Prism, JWST MIRI LRS |
| Transit counts | 5, 10, 20, 100 |
| Products | One POSEIDON-compatible `.dat` file per scenario, instrument, and transit count |

The intended complete active grid gives 32 synthetic datasets:

```text
4 scenarios x 2 instruments x 4 transit counts = 32 datasets
```

These are stored in:

```text
notebooks/POSEIDON_output/TRAPPIST-1e/synthetic_data/base_1transit/
```

This directory can also contain 1-transit reference products and legacy files.
As audited on 2026-06-12, the active 5/10/20/100 naming set contains 28 files:
the A1 and A2 100-transit products are absent. Treat the grid as active rather
than complete until the spectroscopy README or a dedicated report confirms all
32 datasets.

### Retrieval campaign

Full MultiNest retrievals are expensive, so the current queue is narrower than
the full synthetic grid. The source of truth is `DEFAULT_CAMPAIGN` in
`notebooks/run_trappist_retrieval_campaign.py`:

| Scenarios | Transit counts | Instrument modes | Runs |
| :--- | :--- | :--- | ---: |
| A0, A3 | 5, 10, 20, 100 | MIRI, NIRSpec, NIRSpec + MIRI | 24 |
| A1, A2 | 5, 10, 20 | MIRI, NIRSpec, NIRSpec + MIRI | 18 |
| **Current queue total** |  |  | **42** |

The queue runner is skip-aware: existing results are not rerun unless
`--force` is passed.

Legacy retrieval products from the older 10/100-transit exploratory setup may
still exist under `retrievals/`, but they are not part of the updated campaign.
Lifecycle and cleanup notes are tracked in `../experiments/README.md` and
`../experiments/cleanup.md`.

## Interpretation

This module does not replace the chemistry model; it interrogates it
observationally. The current products should be read as detectability
experiments conditioned on TRAPPIST-1e atmospheric profiles that carry a
documented trace-species convergence caveat.
