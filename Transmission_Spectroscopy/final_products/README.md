# Final spectroscopy layer

This directory is the presentation layer for the current TRAPPIST-1e
transmission-spectroscopy analysis. It does not replace the working POSEIDON
output tree. Instead, it records the small set of products that are considered
useful for the current scientific narrative.

## Execution Environment

Run the final spectroscopy layer from Ubuntu/WSL in the Anaconda environment
named `POSEIDON`:

```bash
cd /mnt/c/Proyectos/Astro/ExoFarm_MDwarfs/Transmission_Spectroscopy/notebooks
source /home/dasan/anaconda3/etc/profile.d/conda.sh
conda activate POSEIDON
export POSEIDON_input_data=/mnt/d/Proyectos/IA_SpecAtm_Bio/Data/POSEIDON/inputs/
export PYSYN_CDBS=/mnt/d/Proyectos/IA_SpecAtm_Bio/Data/POSEIDON/inputs/stellar_grids/
```

Then run:

```bash
python make_final_spectroscopy_figures.py
```

The script writes the curated copies to:

```text
Transmission_Spectroscopy/final_products/figures/
```

## Scientific Caveat

The TRAPPIST-1e spectra and retrievals are conditioned on VULCAN profiles
accepted with the documented trace-species partial-convergence caveat. Do not
present these figures as an unqualified detection claim.
