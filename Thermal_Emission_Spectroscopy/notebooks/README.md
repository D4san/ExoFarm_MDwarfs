# Notebooks de la Etapa III

Los futuros notebooks deberán consumir manifiestos y productos ya generados,
no ocultar configuración de instrumento o conversiones dentro de celdas. Cada
notebook separará carga, validación, diagnóstico molecular, visualización e
interpretación.

Todavía no hay notebooks ejecutables.

> **Reanudación:** antes de crear un notebook, leer el [contrato de Etapa III](../README.md), la [guía de reanudación](../../docs/project_resume.md) y el [plan de dos capas](../../docs/life_stage_iii_two_layer_workplan_2026-07-20.md).
