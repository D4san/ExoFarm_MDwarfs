# Productos generados de la Etapa III

No hay productos LIFE todavía. Cuando se active una campaña, sus resultados
vivirán bajo `outputs/<campaign-id>/` con un `manifest.yaml`, forwards,
diagnósticos moleculares, productos LIFEsimMC, tablas, figuras y retrievals.

No guardar aquí archivos de transmisión, PandExo o `.vul` crudos.

> **Reanudación:** no crear `outputs/<campaign-id>/` sin el manifiesto y las puertas indicadas en el [contrato de Etapa III](../README.md) y la [guía de reanudación](../../docs/project_resume.md).
