# Scripts de la Etapa III

Aquí vivirán únicamente adaptadores y validadores reproducibles: lectura de
perfiles VULCAN, forward de emisión POSEIDON, conversión a radiancia LIFEsimMC,
validación de unidades y cálculo SNR/covarianza. No duplicar aquí scripts de
transmisión ni comandos PandExo.

Todavía no hay scripts ejecutables.

> **Reanudación:** antes de escribir un script, leer el [contrato de Etapa III](../README.md), la [guía de reanudación](../../docs/project_resume.md) y el [plan de dos capas](../../docs/life_stage_iii_two_layer_workplan_2026-07-20.md).
